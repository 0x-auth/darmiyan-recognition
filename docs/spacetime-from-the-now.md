$$\Delta t = t + \tfrac{1}{t} \quad(\text{the "now"}), \qquad \Delta x = t - \tfrac{1}{t} \quad(\text{the asymmetry}).$$

## 2. The invariant — the relativistic dispersion relation **[proven]**

$$\Delta t^2 - \Delta x^2 = \left(t+\tfrac1t\right)^2 - \left(t-\tfrac1t\right)^2 = 4\,t\cdot\tfrac1t = 4 \quad\text{for every } t.$$
