## Corrections made on 18 Nov

- The Construct §1 and F2 §2.10 said only four operations keep Δt² − Δx² = 4. In fact every t ≠ 0 keeps it, since (t + 1/t)² − (t − 1/t)² = 4 is an identity. What singles out the eight reflections is that they form a closed group.
